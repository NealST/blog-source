# Computer Use 视频制作拆解

## Style
1080x1920 竖屏技术解说。背景 `#1C1C1E`，前景 `#F2EDE3`，强调色 `#D4A76A`，面板 `#2C2A28`。标题使用 DM Sans 800 与苹方粗体，技术标签使用 JetBrains Mono。整体是暗色工程编辑部与小黑手绘实验记录的混合。

## Rhythm
hook-PUNCH-build-COMPARE-breathe-PEAK-resolve-CTA，8 幕共 88 秒；时长按信息密度分配，并控制在 90 秒上限内。

## Global Rules
- 每幕用坐标网格、准星、细线、编号、状态灯形成 2-5 个背景层，并让网格或准星缓慢漂移。
- 场景之间使用 0.55 秒 blur-through 或纵向速度匹配切换；三家对比用硬切般快速级联。
- 所有文字保持短句；每幕最多一个主标题、一个结论和三组数据。
- 插图使用纸白画布完整呈现，搭配裁切移动，不加装饰性卡套。

## Beats
1. **坐标钩子，0-8 秒**：屏幕坐标 `(135, 193)` 像指令一样敲入，准星迅速锁定“点击”。大号标题从坐标背后压入。BG 网格漂移，MG 标题与坐标，FG 准星、刻度和状态点。向上模糊切换。
2. **共用回路，7.5-17 秒**：四个节点沿一条金色回路依次点亮：观察、思考、行动、循环。连接线绘制，节点级联，最后循环箭头轻微旋转。硬切进入三家对比。
3. **三家差异，16.5-27 秒**：OpenAI、Anthropic、Google 三列快速落位，分别突出截图与代码、物理像素、1000x1000 网格。底部两条坐标轴锁定“感知通道”和“动作空间”。纵向推镜过渡。
4. **OpenAI 的变化，26.5-38 秒**：小黑双控制层插图占据画面上半部；下半部用“单步坐标 → 代码执行”表达工程演进。插图从右侧滑入，箭头绘制，代码片段打字出现。模糊切换。
5. **定位瓶颈，37.5-49 秒**：小黑瞄准像素插图成为主视觉。`看懂 ≠ 点准` 盖章出现，92.7% 数字计数式放大，准星持续呼吸。该幕留出阅读停顿。
6. **像素、元素、混合，48.5-60 秒**：三条路径从左向右铺开；纯像素、元素引用、混合模式各自填充。混合模式在终点以金色亮起，结论“结构优先，视觉兜底”压轴。
7. **安全三件套，59.5-71 秒**：沙箱、人工确认、注入检测三层防线依次合拢。红色风险点冲击并被拦在核心资产之外。强调“单层失效，损害仍可控”。
8. **结论与 CTA，70.5-88 秒**：模块化定位插图淡入，三个结论逐条出现：回路收敛、混合成为主流、安全必须纵深。最后落到公众号“墨筝”，完整技术拆解。

## Recurring Motifs
坐标准星、金色路径、`x/y` 刻度、左上角场景编号、底部运行状态灯。

## Negative Prompt
避免网页式居中卡片堆叠、细小正文、霓虹科技蓝、紫色渐变、虚假 3D、无意义光球、插图被过度裁切、每个元素使用同一种上浮淡入。
