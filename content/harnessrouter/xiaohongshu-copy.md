# 小红书发布文案

标题：一套接口切换26种Agent

Codex、Claude Code、Gemini CLI 的启动方式、事件流和会话恢复机制各不相同，业务系统往往要为每套运行时重复适配。

UHP 把任务分发、流式状态、多轮会话和文件产物统一成 HTTP 契约；HarnessRouter 则把这套协议落成可自托管网关，目前已适配 26 个主流 harness。

真正落地时，还要关注会话隔离、Provider 凭据、幂等重试与社区版的安全边界。完整协议示例、部署方式和生产检查清单见公众号「墨筝」。
