# Design

## Mood
Dark tech — developer tooling, CLI productivity, the feeling of a well-configured terminal glowing in a dim room.

## Colors
- Background: `#0B1222` (deep navy-black, tech-forward shift from 墨色)
- Foreground: `#F0EBE3` (warm white, derived from 宣纸底)
- Accent 1: `#E0A458` (amplified 筝弦金, video-grade warmth)
- Accent 2: `#5B9CF6` (cool blue for contrast, CLI/terminal association)
- Muted: `#162033` (panel backgrounds)
- Border: `#2A3A52` (structural lines, dividers)

## Typography
- Headlines: Montserrat, 800 weight
- Body: Montserrat, 400 weight
- Data/Code: JetBrains Mono, 500 weight

## Constraints
- All text in Chinese except CLI commands, keyboard shortcuts, and tool names
- Monospace for all commands and shortcuts
- No gradient text
- Terminal-green or accent-blue for command highlights acceptable as tertiary accents
