# Design

## Mood
Dark tech — data-driven, precise, authoritative. The feeling of watching a live code review dashboard update.

## Colors
- Background: `#011627` (deep midnight navy)
- Foreground: `#E8ECF0` (cool white)
- Accent 1: `#2EC4B6` (teal — primary data/positive)
- Accent 2: `#FF9F1C` (amber — cost/value highlights)
- Accent 3: `#E71D36` (red — failures/warnings)
- Muted: `#1B3A4B` (panel backgrounds, cards)
- Border: `#2A4A5E` (structural lines, dividers)

## Typography
- Headlines: DM Sans, 800 weight
- Body: DM Sans, 400 weight
- Data/Code: JetBrains Mono, 500 weight

## Constraints
- All text in Chinese except model names and code identifiers
- Monospace for all numbers, costs, and percentages
- No gradient text
- No pie charts
- Teal for "good" data, red for "bad" data, amber for cost/value
