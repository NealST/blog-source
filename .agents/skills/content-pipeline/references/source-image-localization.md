# 原文插图风格适配与中文化

本参考负责审核文章已有插图，并在确有必要时调用已安装的 `topview-generate` skill 做 `image_edit`。目标是让内容型插图适配墨筝主题并服务中文读者，不是把所有图片重新生成一遍。

## 1. 逐图判定

先记录原图路径、正文位置、用途、宽高比和核心信息，再依次判断：

1. **文字是否是主要信息载体**：如果读者不读图中文字就无法理解图意，才进入中文化评估；若图片主要展示视觉效果、产品状态或人物/事件证据，通常保留。
2. **图片是否具有原始证据价值**：产品界面、社交平台原帖、官方文档、论文或基准原图、品牌素材和纪实照片，应优先保留原文，避免翻译后失去来源语境或被误认为二次制作。
3. **中文化是否真的降低理解成本**：能由正文或中文图注准确说明的，不必为了统一语言而重绘。只有外语标题、标签、图例、注释或流程节点构成理解障碍时，才翻译。
4. **翻译是否会改变事实或真实性**：存在文本密集、字号过小、专有名词不确定、真实 UI 文案或来源标记时，默认保留原图。

不是所有英文图片都需要转成中文。判断标准是中文读者的理解收益，而不是图片中是否出现英文。

完成判断后选择一个动作：

| 动作 | 条件 |
| --- | --- |
| `keep` | 风格可接受，且没有影响理解的外语信息 |
| `localize` | 风格可接受，但外语标题、标签、图例、注释或节点妨碍中文读者理解 |
| `restyle+localize` | 风格明显偏离主题，且存在值得中文化的内容 |
| `restyle` | 风格明显偏离主题、没有外语内容，但视觉适配能明显改善整篇一致性 |

社交平台原帖、产品界面和官方材料即使包含大量英文，也通常选择 `keep`，并在正文或图注中提供必要的中文概述。解释型流程图、概念图和数据图若文字本身承担核心信息，且重绘不会损害来源真实性，则可选择 `localize` 或 `restyle+localize`。

风格不匹配的证据包括：高饱和营销模板、与全文不一致的重度渐变/霓虹皮肤、装饰压过信息、字体与颜色体系明显冲突。仅仅不是品牌色，不足以触发重绘；清晰的产品截图、纪实照片、论文原图和带来源的数据图通常保持原样。

适合翻译：自然语言标题、说明、流程节点、坐标轴名称、图例和注释。默认不翻译代码、命令、变量、API 名、产品名、商标、网址、文件路径、版本号、数据、单位以及需要忠实展示的真实 UI 文案。无法确定专有名词译法时保留原文或采用“中文（原文）”，不得猜译。

## 2. 编辑前清单

1. 从正文和图中抄录所有必须保真的事实、数字、单位、节点、箭头关系和来源标记。
2. 列出逐项翻译表，保持术语与文章正文一致；不把翻译任务完全交给图像模型自行判断。
3. 明确允许调整的视觉项：背景、配色、字体、装饰和留白。默认保持构图、主体、信息层级与宽高比。
4. 涉及付费生成时遵循 `topview-generate` 的首次计费确认；同一批后续任务是否自动继续，以用户授权为准。

## 3. Topview 执行

完整 MCP、上传、选 board、实时模型配置、提交和轮询流程以 `../../topview-generate/SKILL.md` 为准，不运行其脚本、不调用旧 REST API。图像编辑使用 `topview_generate_image` 的 `image_edit`，优先选择实时配置中兼容且擅长文字渲染的 GPT Image 2；不可用时按该 skill 的模型建议选择，不能静默换模型。

开始前确认宿主已连接 `topview-mcp`，并能看到 `topview_*` 与 `ta_*` 工具。未连接时停止并请用户在宿主中启用该 MCP；需要认证时只执行 skill 规定的宿主登录流程，不索取 API key，也不回退到 `scripts/topview_image_gen.py`。

提示词至少包含：

- 这是保真编辑，不是重新设计信息或补写内容。
- 原图中哪些文字必须逐项替换为哪些中文。
- 哪些代码、品牌、数字、单位、来源和 UI 文案必须原样保留。
- 保持主体、布局、节点、箭头、数据关系、裁切和宽高比。
- 视觉适配时使用纯白或克制浅底、墨色 `#1C1C1E`、少量筝弦金 `#C4956A`；不增加 Logo、水印、无关文字、重渐变或装饰性光效。
- 中文必须清晰、无乱码、无漏字、无擅自缩写。

每张图默认只生成 1 个结果。先处理一张代表图并验收，再批量处理同类图片，避免重复消耗 credits。保存结果时下载到 `content/[slug]/localized-images/NN-original-name.png`，并保留原图。

## 4. 验收门禁

必须实际查看原图与结果图并逐项对照：

- 所有计划翻译的文本均已正确替换，术语与正文一致；没有乱码、错别字或新增文字。
- 未计划翻译的代码、名称、数字、单位、来源和品牌标识保持准确。
- 节点数量、箭头方向、图例映射、数据关系、主体身份和关键物体没有变化。
- 中文在正文实际显示宽度下可读，没有溢出、遮挡、过小或低对比。
- 宽高比与原图一致，没有意外裁切、拉伸或额外画布。
- 风格适配克制，信息仍是第一视觉层级，并与同篇文章其他插图协调。

任一项失败时，先用同一任务意图修正一次；重生成会额外消耗 credits，必须遵守用户的计费授权。仍不通过则使用原图并在交付中列出未完成项，不得手工声称图片已中文化。

## 5. 接入产物

审核清单或 shot list 为每张原图记录：原路径、动作、判定理由、翻译表、输出路径和验收结果。通过后统一替换下游引用：Markdown、公众号 `preview.html`、小红书独立原图素材和 manifest 应指向同一张处理后图片。不得覆盖原始文件，也不得让不同平台使用未经说明的不同译文。
