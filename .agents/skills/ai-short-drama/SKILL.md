# AI 短剧分镜管线 (AI Short Drama Pipeline)

> 把一个剧情创意，沉淀为可直接交付给 AI 视频工具与剪辑后期使用的工业级分镜台本。

核心目标：**降低 AI 视频生成的不确定性**（角色崩坏、布景漂移、嘴型不同步、字幕乱码、版权拦截），让分镜稿"开箱即用"。

---

## 触发词

| 触发词 | 行为 |
|-------|------|
| `生成 AI 短剧脚本` / `写个短剧` | 启动完整流程：剧本 → 分镜 → 角色画像 |
| `做短剧分镜` | 已有剧本，直接做分镜拆解 |
| `短剧角色画像` | 生成动画化角色基准图提示词 |
| `打磨剧本` | 多轮迭代既有剧本（玩梗 / 校正事实） |
| `转英文台词` | 把中文台词翻译为美式口语 + 标注情绪 |

---

## 存储规范

短剧产物独立于 `content/`，存放在 `dramas/[slug]/`：

```
dramas/[slug]/
├── brief.md              # 创意 brief（角色、设定、世界观、关键事实）
├── script.md             # 文字剧本（多轮打磨的最终版）
├── storyboard.md         # 分镜台本（最终交付物）
├── characters.md         # 角色画像提示词（动画化）
├── background.md         # 统一背景方案（坐标锁定 / Seed / 绿幕底图）
├── prompts/              # 各分镜的 AI 视频提示词（按镜号）
│   ├── shot-01.txt
│   └── ...
└── assets/               # 生成的角色基准图 / 背景底图
```

**slug** = 短剧主题英文短横线命名（如 `cancun-trio`、`silicon-valley-coffee`）。

## 工作流（七步法）

### Step 1：Brief 收集（明确事实地基）

**必须先和用户对齐的要素**：
- **角色**：谁出场？现实人物 / 虚构人物？关键梗与人设标签
- **时间锚点**：故事发生在哪一天？季节、天气、时事背景
- **关键事实**：剧情依赖的硬事实（如"哈登首轮和半决赛都打了抢七"）
- **基调**：纯喜剧 / 喜剧 + 走心 / 反转 / 致敬 / 黑色幽默
- **目标平台与时长**：短视频（30-60s）/ 中视频（2-3min）

→ 输出 `brief.md`。**事实校正越早越好**，避免后期重构剧本。

### Step 2：剧本多轮打磨

**打磨原则**：
1. 用户补充事实只作为"地基"，不一定强行写进台词
2. 喜剧节奏遵循"反差 → 冲突 → 反转 → 余味"
3. 每个角色至少绑定 2-3 个**辨识度极高的梗**（视觉梗 + 语言梗）
4. 走心段落必须紧接喜剧反差（避免说教感）
5. 结尾"破功 + 致敬"双结构（笑中带泪）

**单角色梗资产示例**：
- 视觉梗（动作 / 道具 / 装扮）：詹姆斯的《教父》第一页 / 库里的牙套
- 语言梗（口头禅 / 引用）：杜兰特的"小号" / 哈登的"良禽择木"

→ 输出 `script.md`。

### Step 3：角色画像设计（规避版权）

**核心策略**：用 3D 动画夸张风格替代真人，特征化处理。

**画风底词（统一）**：
```
3D stylized animation caricature, Pixar / Spider-Verse style,
exaggerated features, vibrant colors, cinematic lighting, 8k.
```

**规避版权三原则**：
1. **不写真实姓名**，只写"皮肤色 + 体型 + 标志性特征 + 着装"
2. **放大单一辨识度特征**（哈登的胡子 / 杜兰特的修长四肢）
3. **配色暗示球队归属**（紫金 = 湖人 / 酒红 = 骑士），不写队名

→ 输出 `characters.md`，详见 `references/character-template.md`。

### Step 4：背景一致性方案

**问题**：同一片沙滩，AI 每次生成海浪角度都不同 → 多镜头拼接穿帮。

**三层解决方案**（优先级递增）：

| 方案 | 适用场景 | 操作 |
|------|---------|------|
| A. 坐标锁定提示词 | 镜头数少（< 6） | 在每条 prompt 里固定阳光方向、椰树位置、沙滩台等元素 |
| B. Seed 固定 | Midjourney / SD 工作流 | 第一张选定后获取 seed，后续全部复用 `--seed xxx` |
| C. 绿幕合成（工业级） | 镜头数多 / 严格一致 | 角色加 `green screen background`，统一底图后期合成 |

→ 输出 `background.md`。

### Step 5：分镜拆解

**分镜节奏**：
- 单镜时长 **4-8 秒**（AI 视频甜区）
- 优先**多人同框（2-Shot / 3-Shot）**，少切碎镜
- 关键情绪点用单人特写（推镜头 + 静音留白）

**每个分镜必须包含的 8 个字段**：
1. 🕘 **总时长**
2. 📍 **布景**（引用 background.md 的某个坐标方案）
3. 👔 **服装**（每个出场角色，每镜复述一次防 AI 遗忘）
4. 🎬 **动作与表情**（微表情 + 肢体语言）
5. ⏱️ **说话顺序与时序**（精确到秒，标注谁先说、谁静音）
6. 🎙️ **英文配音 + 中文字幕**（含语气指导 Tone）
7. 🎥 **运镜**（机位、景别、推拉摇移）
8. 🔄 **转场**（向下一镜的衔接方式）

→ 输出 `storyboard.md`，详见 `references/storyboard-template.md`。

### Step 6：中英双语台词

**为什么必须英文**：AI 视频对中文口型同步极差，强行中文配音会出现"瞎对口型"。

**翻译原则**：
1. 译为**美式口语 + NBA / 网络俚语**（"flame haters"、"team-hopping maniac"）
2. 保留双关与梗（"LeGM"、"The Decision 4.0"）
3. 每句标注 🎙️ **Tone**（语速 / 音调 / 情绪关键词）
4. 中文字幕单独成行，作为后期叠加素材

### Step 7：转场与运镜指导

**常用转场术语对照**：

| 术语 | 中文 | 适用场景 |
|------|------|---------|
| J-Cut | 声音前置引导 | 用下一镜的音效提前 0.5s 切入做引导 |
| Smash Cut | 情绪反差硬切 | 喜剧反差（感动 → 破功） |
| Crash Zoom | 极速推镜头 | 进入设备屏幕 / 引爆情绪 |
| Cross Dissolve | 叠化过渡 | 走心段落 / 时空共鸣 |
| Eyeline Match | 视线匹配 | 两个空间的角色"对视" |
| Motion Match | 动势匹配 | 物体飞过 / 动作延续 |
| Fade to Black | 黑场淡出 | 结尾收束 |

**反派音效清单**（打破煽情用）：
- 推特发送 Swoosh
- 手机消息提示音
- 玻璃杯倒地
- 球类砸地

## 关键避坑清单

| 坑 | 规避方法 |
|---|---------|
| AI 生成中文字幕乱码 | **所有画面内文字（书名、UI、字幕）全部后期合成**，提示词里只写 `thick book` 不写《教父》 |
| 角色服装跨镜头变化 | 每个镜头的 prompt **完整复述服装描述**，不依赖"上文记忆" |
| 多人镜头说话顺序混乱 | 用 ⏱️ 字段精确标注秒数、谁先说、谁此刻必须静音 |
| 真人姓名触发版权拦截 | 用"特征 + 配色"暗示身份，不写姓名 / 队名 |
| 嘴型对不上中文配音 | 全程用英文配音，中文走字幕 |
| 镜头之间割裂 | Step 7 的转场设计必须配合 Step 5 的剧情节奏 |
| 走心段落过于说教 | 紧跟一个喜剧反差（例：致敬 → 推特发送音 → 老詹暴怒） |

---

## 一句话原则

> **"AI 只负责动起来，确定性由提示词和后期承担。"**

把所有不确定的东西（字幕、UI、特定文字、复杂手势）从 AI 生成环节剥离，
让 AI 只做它最擅长的事——让一个动画化的形象做一个简单动作。
